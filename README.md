# ⚖️ Jargon Breaker — AI Document Clarity Engine & Executive HUD

> Demystify fine print, expose dangerous clauses in **Red**, verify standard terms in **Green**, and generate instant negotiation playbooks for Legal, Medical, and Government documents.

---

## 🌟 Key Features

- **📊 Executive Modern Intelligence Dashboard**:
  - Live AI Neural Radar HUD with active telemetry.
  - 3D Radial Risk Gauge (0-10) with dynamic SVG dials.
  - Clause Breakdown Radar (🔴 Risky vs 🟢 Normal).
  - Critical Response Timelines & strict deadline forfeiture warnings.
  - Financial Liability & Penalty Detector.
  - Two-Column Intelligence Matrix (Top Hazards & Negotiation Playbook).
  - 1-click switcher between **⚖️ Executive Briefing** and **👶 Simple (5th Grader)** explanation modes.
- **🔍 Interactive Clause Inspector**:
  - 🔴 **Red Highlights**: Unfair, aggressive, penalty, and forfeiture clauses.
  - 🟢 **Green Highlights**: Standard, fair, routine, and safe terms.
  - Click-to-inspect popovers with reasons and verbatim quotes.
- **⚡ Negotiation Playbook & Action Plan**:
  - Step-by-step checklist with priority tags.
  - Pre-drafted counter-proposals and ready-to-send questions.
  - Click-to-jump: Scrolls and flashes the exact clause in the document text.
- **💬 Grounded Document Q&A**:
  - Chat with your document with strict citations and source quotes.
- **📸 Universal Document Support**:
  - Supports **PDF documents** (.pdf), **Photos / Scans** (.jpg, .jpeg, .png, .webp), and **Text** (.txt, .md).
  - Built-in OCR with image verification (rejects photos of people/characters with clear guidance).
- **📥 PDF Dossier Export**:
  - Instant one-click PDF download of complete analysis reports.
- **🌐 Multilingual Support**:
  - Full translations for **English**, **Tamil (தமிழ்)**, and **Hindi (हिंदी)**.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup (Optional)
Create a `.env` file in the root directory:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Build for Production
```bash
npm run build
```
